## 📌 نبذة عن المشروع

**Qivora Download Manager** برنامج لنظام ويندوز كُتب بلغة **Rust** وواجهة **Slint**، يجلب الملفات من الروابط التي يحددها المستخدم ويحفظها على جهازه بأقصى سرعة.
يقسّم البرنامج الملف على عدة اتصالات متوازية، ويستأنف العمل من حيث توقف إذا انقطع الاتصال، ويدعم الوضع الفاتح (Light Mode) والوضع الداكن (Dark Mode) مع تبديل فوري، كما تدعم واجهته **ثماني لغات**: العربية والإنجليزية والفرنسية والإسبانية والألمانية والبرتغالية والتركية والروسية.

> [!IMPORTANT]
> يتحمّل المستخدم مسؤولية احترام حقوق الملكية وشروط استخدام أي محتوى يتعامل معه من خلال البرنامج.

## ✨ المزايا

| الميزة | التفاصيل |
|---|---|
| 🔀 **اتصالات متعددة** | تقسيم الملف على ما يصل إلى 32 اتصالًا في الوقت نفسه |
| ⏯️ **الاستئناف** | الإيقاف المؤقت والاستئناف في أي وقت، حتى بعد إغلاق البرنامج |
| 🌐 **إضافة للمتصفح** | استقبال الملفات من المتصفح (Chrome / Edge / Brave / Opera / Vivaldi / Firefox)، مع خطوات تركيب الإضافة من داخل البرنامج |
| 🎬 **الفيديو والصوت** | حفظ الفيديو والصوت من الصفحات وقوائم التشغيل مع اختيار الجودة |
| 🧲 **التورنت (BitTorrent)** | دعم ملفات `.torrent` وروابط `magnet:` مع اختيار الملفات الداخلية |
| 🗂️ **تصنيف تلقائي** | وضع كل ملف في المجلد المناسب لنوعه |
| ⏰ **قوائم انتظار وجدولة** | قوائم انتظار، وتشغيل في موعد محدد، وإيقاف تشغيل الجهاز عند الانتهاء |
| 🐢 **تحديد السرعة** | حدّ عام للسرعة أو حدّ خاص بكل ملف |
| 🔎 **Site Grabber** | جمع الملفات من صفحة كاملة دفعة واحدة |
| 📋 **القوائم** | إضافة روابط متعددة دفعة واحدة، واستيراد القوائم وتصديرها |
| 🌓 **الوضع الفاتح والداكن** | دعم كامل لكلٍّ من Light Mode و Dark Mode |
| 🌍 **ثماني لغات** | العربية، English، Français، Español، Deutsch، Português، Türkçe، Русский |

## 📦 التثبيت

ثبّت البرنامج من **GitHub Releases** في صفحة المشروع (`Qivora-Setup.exe`):
https://github.com/kplejojo-del/Qivora/releases

يُثبَّت البرنامج للمستخدم الحالي ولا يحتاج إلى صلاحيات المسؤول.

### البناء من الشيفرة المصدرية

شغّل الملف **`BUILD.bat`**، وستجد ملف الإعداد `Qivora-Setup.exe` في مجلد **`dist`**.

## 🔍 سلوك البرنامج واتصالاته

حرصًا على الوضوح، هذه هي المهام التي يؤديها البرنامج تلقائيًا:

| الوظيفة | التفاصيل |
|---|---|
| 🔄 **تحديث البرنامج** | عند التشغيل وكل 6 ساعات يقرأ البرنامج ملف `version.json` من GitHub Releases الخاصة بالمشروع (`kplejojo-del/Qivora`). إذا وُجد إصدار جديد موقّع بمفتاح Ed25519 الرسمي، يجلبه من GitHub Releases فقط، ويتحقق من بصمة SHA-256 والتوقيع الرقمي، ثم يثبّته ويعيد تشغيل نفسه. ويمكن البحث عن التحديثات يدويًا من قائمة Help ← Check for updates. |
| 🧰 **الأدوات المساعدة** | يستخدم البرنامج أداتي yt-dlp و FFmpeg و aria2c (الموجودة في مجلد `tools`)، ويتحقق من بصمة SHA-256 عند تنزيلها أو تحديثها. |
| 🔌 **الاتصال بالإضافة** | يفتح البرنامج منفذًا محليًا على `127.0.0.1` (الافتراضي 9614) لتتواصل معه إضافة المتصفح. هذا المنفذ غير متاح من الشبكة، ويرفض أي طلب لا يأتي من الإضافة. |
| 🍪 **ملفات تعريف الارتباط** | ترسل الإضافة إلى البرنامج ملفات تعريف الارتباط وعنوان الصفحة الخاصين بالملف المطلوب فقط، لكي تعمل الروابط التي تتطلب تسجيل الدخول. تنتقل هذه البيانات إلى البرنامج على الجهاز نفسه فقط. |
| 📋 **الحافظة** | يراقب البرنامج الحافظة، وإذا نُسخ رابط لملف يعرض إضافته. يمكن إيقاف ذلك من الإعدادات. |
| 🚀 **التشغيل مع ويندوز** | خيار اختياري أثناء التثبيت، ويمكن تغييره من الإعدادات. |
| 💾 **البيانات** | تُحفظ الإعدادات وقائمة الملفات في `%APPDATA%\Qivora\QivoraDownload\data`، وتُشفَّر كلمات المرور وملفات تعريف الارتباط محليًا باستخدام Windows DPAPI (`CryptProtectData`). |

البرنامج **لا يجمع ولا يرسل** أي بيانات استخدام أو إحصاءات إلى أي جهة.

## 🗂️ هيكل المشروع

```
├─ crates/engine/      محرك التحميل والتحديث الذاتي
├─ crates/app/         تطبيق سطح المكتب (واجهة Slint)
│  ├─ ui/              تصميم النوافذ والسمات (Light / Dark)
│  └─ lang/            ترجمات الواجهة (8 لغات)
├─ extension/          إضافة المتصفح (Chrome / Firefox)
├─ installer/          ملف إعداد المثبّت (Inno Setup)
└─ BUILD.bat           أمر البناء الشامل لنظام ويندوز
```
